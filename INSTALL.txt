───────────────────────────────────────────────────────────────────
Quick Railway Deployment (3 Steps):
───────────────────────────────────────────────────────────────────

1. Create a New Project on Railway:
   • Go to https://railway.app
   • Click "+ New Project" -> "Deploy from GitHub repo" (or upload this folder via Railway CLI: `railway up`).

2. Add MySQL Database:
   • In your Railway project canvas, click "+ Create" -> "Database" -> "Add MySQL".
   • Railway will automatically link the MySQL service and inject:
       MYSQLHOST, MYSQLUSER, MYSQLPASSWORD, MYSQLDATABASE, MYSQLPORT

3. Initialize the Database (1-Click):
   • Once your web service is deployed, open your Railway domain in your browser:
       https://YOUR-APP.up.railway.app/railway-seed.php
   • Click "Initialize & Seed Database Now".
   • All 28 database tables and default site settings are instantly created!

Local Testing (Optional):
───────────────────────────────────────────────────────────────────

  If you have PHP and MySQL installed locally:
    1. Import schema.sql into your local MySQL database.
    2. Set environment variables (or edit scripts/connect.php):
       DB_HOST=localhost DB_USER=root DB_PASS="" DB_NAME=bank
    3. Run:
       php -S localhost:8000 router.php
    4. Open http://localhost:8000 in your browser.
